# 雲端後端部署步驟（只需做一次，約 10 分鐘）

這份文件給**專案擁有者**（資料要存進誰的 Google 帳號，就用誰的帳號做）。
做完之後，巡檢人員不需要 Google 帳號（只要用白名單 email 登入 Cloudflare），資料就會統一進到你的雲端。

```
手機網頁 ──登入──> Cloudflare（catpatrol.a-wen90.workers.dev）──帶 token 代轉──> Apps Script ──> 試算表／Drive
```
Apps Script 網址和 token 只存在 Cloudflare 後台，手機上看不到。

---

## 1. 建立 Apps Script 專案

1. 用你的 Google 帳號登入，開啟 <https://script.google.com/>
2. 左上角點「**新增專案**」
3. 專案名稱點一下改成 `CATPatrol 後端`（左上角預設是「未命名專案」）

## 2. 貼上程式碼

1. 編輯器中間預設有一個 `Code.gs`（或 `程式碼.gs`），把裡面的內容**全部刪掉**
2. 打開本資料夾的 [`code.gs`](code.gs)，**全選複製**，貼進編輯器
3. 找到這一行（約第 8 行）：
   ```js
   const TOKEN = 'CHANGE_ME';
   ```
   把 `CHANGE_ME` 改成**你自訂的一串長一點的亂碼**（例如 `cp-7Hq2-xR9m-2026`）。
   這串字等一下要填進 Cloudflare，用來擋掉不相干的人亂送資料。**請記下來。**
4. 按 💾 儲存（Ctrl+S）

## 3. 首次授權並建立試算表

1. 編輯器上方的函式下拉選單，選 **`setup`**
2. 按「**執行**」
3. 第一次會跳出授權視窗：
   - 點「**審查權限**」→ 選你的帳號
   - 出現「Google 尚未驗證這個應用程式」→ 點左下角「**進階**」→「**前往 CATPatrol 後端（不安全）**」
   - （這是你自己寫的程式、只存取你自己的檔案，所以是安全的。這個警告是因為沒有經過 Google 商店審核。）
   - 點「**允許**」
4. 執行完後，下方「執行記錄」會印出兩個網址：
   - 試算表 `CATPatrol_資料庫` — 之後所有巡檢資料都在這
   - 照片資料夾 `CATPatrol_照片` — 之後所有照片都在這
   
   點進試算表確認有 5 個分頁：專案、設備、巡檢紀錄、自訂欄位定義、照片索引。

## 4. 部署成網頁應用程式

1. 右上角「**部署**」→「**新增部署作業**」
2. 左邊齒輪 ⚙️ →選擇類型→「**網頁應用程式**」
3. 設定：
   | 項目 | 要選什麼 | 為什麼 |
   |---|---|---|
   | 說明 | `v1` | 隨意 |
   | 執行身分 | **我（你的信箱）** | 這樣資料才會寫進**你的**試算表 |
   | 誰可以存取 | **所有人** | Cloudflare 代轉時不會帶 Google 登入；靠 TOKEN 擋外人 |
4. 按「**部署**」
5. 複製「**網頁應用程式網址**」，長得像：
   ```
   https://script.google.com/macros/s/AKfycb...../exec
   ```
   **這串網址就是 API 網址。**

> ⚠️「誰可以存取：所有人」不代表任何人都能看到你的資料 —— 程式只接受帶正確 TOKEN 的請求，
> 而且只能新增資料、無法讀取或刪除你的其他檔案。但 TOKEN 請勿公開貼在網路上。

## 5. 填進 Cloudflare

1. 開啟 Cloudflare 後台 → **Workers & Pages** → 點 `catpatrol`
2. **Settings** →「**Variables and Secrets**」→「**Add**」，新增兩筆，Type 都選 **Secret**（加密、之後看不到內容）：
   | Variable name | Value |
   |---|---|
   | `APPS_SCRIPT_URL` | 第 4 步的網頁應用程式網址 |
   | `API_TOKEN` | 第 2 步自訂的那串字 |
3. 按「**Deploy**」讓設定生效

完成。巡檢人員的手機什麼都不用設定，登入後就能上傳。
（Secret 存在 Cloudflare，之後 GitHub push 重新部署也不會被洗掉。）

---

## 之後修改程式碼時

改完 `code.gs` 後要重新部署才會生效：
1. 貼上新程式碼後，**記得把 TOKEN 改回你的那串字**（新程式碼裡是 `CHANGE_ME`）→ 儲存
2. 函式下拉選 **`setup`** →「執行」一次（有新增欄位時補上標題列；重複執行不會影響資料）
3. 「部署」→「**管理部署作業**」→ 右上角 ✏️ 鉛筆 →「版本」選「**新版本**」→「部署」

**網址不會變**，Cloudflare 不用重設。（換了 TOKEN 才需要同步更新 Cloudflare 的 `API_TOKEN`。）

（若選「新增部署作業」會產生**新網址**，舊網址仍指向舊程式碼 —— 請避免。）

## 疑難排解

| 症狀 | 原因與處理 |
|---|---|
| App 顯示「token 不正確」 | Cloudflare 的 `API_TOKEN` 與 `code.gs` 的 TOKEN 不一致（常見原因：貼新版程式碼後忘了把 TOKEN 改回來） |
| App 顯示「Worker 尚未設定 APPS_SCRIPT_URL / API_TOKEN」 | 第 5 步的兩筆 Secret 沒設，或名稱打錯 |
| App 顯示「Apps Script 回傳的不是 JSON」 | 部署時「誰可以存取」沒選「所有人」 |
| App 顯示「登入已過期」 | 到「同步」分頁按「重新登入」，用白名單 email 收驗證碼 |
| 資料寫到別人的試算表 | 部署時「執行身分」沒選「我」 |
| 想換一個新的試算表 | 專案設定 → 指令碼屬性 → 刪除 `SS_ID` → 重跑 `setup()` |
| 照片沒進 Drive | 檢查 Drive 是否已滿；單張上限約 50MB（App 壓縮後約 300–500KB，正常不會超過） |
