#項目做法
P1電池「全部換」勾到的每台都帶一台份（外接電源的不算）。
P2電池「50% 以下才換」電量 50%（含）以下，或離開時未運作的，才帶。
P3電池總數第一行寫「共 N 台份」，下面再依類型分。
P4記憶卡「每台一張」＝勾幾台帶幾張；「備一半」「備 1/3」無條件進位（7 台備一半＝4 張、備 1/3＝3 張）。
P5防護「全部上防護」勾到的相機只要防護不齊（缺鐵殼、鎖、遮雨板任一樣，或還沒填過），就帶一整套：清單寫「防護套件 N 套」。
P6防護「補缺漏」只帶缺的那幾樣，分開算：「鐵殼 N 個、鎖 N 個、遮雨板 N 片」。還沒填過的當作三樣都缺。
P7下方清單只留「全選」「清除」，每台自己打勾；剛打開時全部不勾。每台右邊用圖示標出要帶什麼。
P8記住選擇上面三排的選擇會記住（每支手機各自記），下次打開還是上次選的。
P9說明文字（頁面最下方）改成：「電池與防護怎麼算，依上面的選擇。外接電源的相機不帶電池；還沒填過防護的，當作都缺。」

#現在改成
A1設備（分頁「設備」、設備清單、新增設備、設備設定、儲存設備、照片資料夾說明「專案／設備／日期」…） 相機（分頁「相機」、相機清單、新增相機、相機設定、儲存相機、「專案／相機／日期」） 現場都說相機，你也說「相機設定」；一台設備就是一台相機。試算表分頁名稱「設備」不改（CATBase 也在讀）。
A2序號、設備序號（卡片「序號 CA001 · Meidase P70」、地圖說明框「序號 CA001」、比對卡「樣點 / 序號」） 相機編號（卡片「CA001 · Meidase P70」、說明框「CA001」、比對卡「樣點 / 相機」） 輸入時叫「相機編號」，顯示時卻叫「序號」，同一個東西兩種叫法。
A3相機故障（徽章）、故障/沒電（地圖圖例）、相機故障或沒電（比對卡、履歷） 未運作（徽章、圖例）；比對卡「⛔ 未運作」；履歷「⚠️ 離開時未運作」 這個狀態包含故障、沒電、被偷；「故障」只說到其中一種。
A4圖例「逾2月未巡／逾3月／逾4月」 「逾2個月／逾3個月／逾4個月」跟清單上的徽章「逾2個月未巡」說法一致。
A5佇列（「上傳佇列」「完成巡檢（離線暫存 → 佇列）」） 待上傳（「待上傳的資料」「儲存巡檢」）「佇列」是程式用語。
A6感度 靈敏度相機選單的常見說法。設定摘要（也寫進試算表「新設定摘要」欄）會從「感度中」變成「靈敏度中」，舊列不變。
